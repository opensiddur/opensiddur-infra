# Software notices

Application code uses LGPL-3.0-or-later. `LICENSE` contains LGPLv3 and `COPYING` contains its incorporated GPLv3 text. The upstream processor declares LGPL-3.0-or-later. Every project text retains the license in its TEI header; generated colophons provide the text/source credits.

`/licenses` is public, linked from the footer and backed by the deployed bundle's notices inventory. `scripts/notices.py` collects installed Python distribution license texts, Debian/TeX/font copyright files and shared license texts. `scripts/frontend-notices.mjs` collects production frontend dependencies and their license/notice files. Source links and versions are recorded. The worker's software-notices JSON is included in full output ZIPs.

Review the inventory before public launch for components whose package metadata lacks a license expression, attribution obligations, missing source links, and redistribution requirements. A generated page is not a substitute for meeting applicable license terms. Pin source versions, preserve license files, and publish modifications/source as required by the actual licenses. Do not describe the software license as applying to liturgical texts or user-provided logos.
